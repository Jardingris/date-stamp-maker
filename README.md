# 日付印メーカー

ブラウザだけで透過背景の日付印を作成できる、単一HTMLファイルのツールです。インストールや外部通信は必要ありません。

## 主な機能

- 上段・下段に各8文字まで入力して日付印を生成（両方とも空欄可）
- 上下の文字数が近い場合は文字サイズをそろえ、差が大きい場合は確認を表示
- 4桁年と短縮年（`2026` → `'26`）の切り替え
- 透過PNGをクリップボードへコピー
- 透過PNG・SVG・Acrobat用PDFとして保存
- PNGサイズを小（256px）・中（512px）・大（1024px）から選択
- 入力内容をブラウザへ保存せず、完全オフラインで動作

## 使い方

1. `stamp.html` をダウンロードします。
2. ブラウザで `stamp.html` を開きます。
3. 上段・下段・日付を設定します。上下段は各8文字以内で、空欄でも構いません。
4. 必要に応じて年表示とPNGサイズを選びます。
5. 用途に応じてコピーまたは保存ボタンを使います。

通常の使用ではPNGサイズの「小」が適しています。貼り付け後、用途に合わせてサイズを調整してください。

- 文書へ貼り付ける場合：通常は「透過PNGをコピー」または「PNGを保存」
- 大きく拡大・縮小する場合：「SVGを保存」
- Acrobat Readerでスタンプとして使う場合：「Acrobat用PDFを保存」後、カスタムスタンプとして登録

## 補足

ブラウザの権限制限により、クリップボードへ直接コピーできない場合があります。その場合は「PNGを保存」を使用してください。SVGはベクター形式のため、拡大・縮小しても輪郭が劣化しません。

Acrobat Readerへ透過PNGを直接貼り付けると、環境によって透明部分が黒くなることがあります。その場合は、約30mm角で出力されるAcrobat用PDFをカスタムスタンプとして登録してください。PDF生成に対応していないブラウザでは、最新のEdgeまたはChromeを使用してください。

## ファイル構成

- `stamp.html` — アプリ本体。CSSとJavaScriptを含む自己完結ファイルです。
